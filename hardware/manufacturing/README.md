# Manufacturing package

Upload `macropad_gerbers.zip` directly to a PCB manufacturer's quote tool.

The archive contains:

- `MacroPad-F_Cu.gbr` and `MacroPad-B_Cu.gbr`
- `MacroPad-F_Mask.gbr` and `MacroPad-B_Mask.gbr`
- `MacroPad-F_Silkscreen.gbr` and `MacroPad-B_Silkscreen.gbr`
- `MacroPad-Edge_Cuts.gbr`
- `MacroPad-PTH.drl` and `MacroPad-NPTH.drl`

Recommended order settings are two layers, 1.6 mm FR-4, 1 oz copper, red solder mask, and white silkscreen. Always use the manufacturer's viewer to verify the outline, holes, polarity markings, and layer alignment before placing an order.
